RadioRoom brings a shared acoustic space, linked mix compression, oversampled tube saturation and 1920s–1950s radio colour to entire mixes.

This first GitHub release adds daily automatic update checks, manual update controls in both formats, visible download progress, verified packages and staged installation with rollback. The VST opens the standalone updater; no updater thread runs inside the DAW.

Windows x64: VST3 effect and standalone. Extract the Windows ZIP, open RadioRoom, and run Install-RadioRoom.cmd. Save and close DAWs using RadioRoom before updating. Source and SHA-256 checksums are included.
